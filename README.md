# 吕怡纬 · Yiwei Lyu

**已推免至中国科学院大学计算机应用技术专业**。本科就读于郑州大学人工智能拔尖创新班，关注机器人操作、多模态交互与智能硬件。

我研究机器人怎样接触环境、完成操作，以及更自然地与人交流。过往工作包括跨水空机器人的双稳态抓附机构、可重构末端执行器、六推进器水下机器人和人形面部交互系统。

在跨水空机器人课题中，我主要负责机构设计与验证，完成二十余轮结构迭代。从 SolidWorks 建模、Abaqus 分析，到 3D 打印、硅胶浇注和样机实验，我习惯先分析载荷、约束和接口，再检查仿真与实验是否支持自己的判断。

我也曾负责学生创新中心与 AI 与大数据科学协会的工作，组织技术训练、科创分享和竞赛组队。做项目之外，我喜欢把加工与调试中遇到的问题整理下来，让下一位同学更容易完成自己的第一台样机。
